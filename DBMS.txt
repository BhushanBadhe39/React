• Introduction of ER Model
--- The Entity-Relationship Model (ER Model) is a conceptual model for designing a database. This model represents the logical structure of a database, including entities, their attributes, and relationships between them.

Entity: An object that is stored as data. E.g: Student, Course, or Company.
Attribute: Properties that describe an entity. E.g: StudentID, CourseName, or EmployeeEmail.
Relationship: A connection between entities. E.g: Student enrolls in a Course.



• Use ER Diagrams In DBMS
ER diagrams represent the E-R model in a database, making them easy to convert into relations (tables).
These diagrams serve the purpose of real-world modeling of objects which makes them intently useful.
Unlike technical schemas, ER diagrams require no technical knowledge of the underlying DBMS used.
They visually model data and its relationships, making complex systems easier to understand.



Types of MySQL Queries
-- DDL -> Data Definition Language
    --- CREATE, ALTER, DROP, TRUNCATE, RENAME

-- DML -> Data Manipulation Language
    --- INSERT, UPDATE, DELETE

-- DCL -> Data Control Language
    --- GRANT, REVOKE

-- TCL -> Transaction Control Language
    --- COMMIT, ROLLBACK, SAVEPOINT

--- DQL -> Data Query Language
    --- SELECT

Create -> is used to create a new table in the database. It defines the structure of the table, including column names, data types, and constraints.

Alter -> is used to modify the structure of an existing table. It allows you to add, delete, or modify columns in a table.
        functions: Add, Drop, Modify, Rename, change, etc.

Drop - > deletes an entire table. It removes the table structure and all its data from the database. Once a table is dropped, it cannot be recovered unless you have a backup.

Truncate -> deletes all the records from a table but keeps the structure of the table intact. It is faster than drop because it does not log individual row deletions.

Rename -> is used to change the name of an existing table in the database.

Insert -> is used to add new records (rows) to a table. It allows you to specify the values for each column in the new record.

Update -> is used to modify existing records in a table. It allows you to change the values of one or more columns for specific records based on a condition.

Delete -> is used to remove existing records from a table. It allows you to specify which records to delete based on a condition.

--- Constraints means we are applying a certain condition or restriction on the database. Before inserting data into the database we are checking for some conditions, if the condition we applied is true then the data is to be inserted.


• Not Null
--- Whenever a column is declared as not null, then the value of that column cannot be empty.

Syntax:
CREATE TABLE table_name (
    column1 datatype NOT NULL,
    column2 datatype,
    ...
);


• Unique
--- Used to restrict duplicate values


• Primary Key
--- it is a column that is used to identify unique records or rows from table. Each table contains only one primary key column. It is a combination of not null and unique constraint.

Syntax:
CREATE TABLE table_name (
    column1 datatype PRIMARY KEY,
    column2 datatype,
    ...
);

--OR--

CREATE TABLE table_name (
    column1 datatype NOT NULL UNIQUE,
    column2 datatype,
    ...
);


• Default
--- It is used to provide a default value for a column when no value is specified during insertion.

Syntax:
CREATE TABLE table_name (
    column1 datatype DEFAULT default_value,
    column2 datatype,
    ...
);


• Check
--- It is used to ensure that the value in a column meets a specific condition.

Syntax:
CREATE TABLE voters(
    voter_id INT PRIMARY KEY,
    age INT CHECK (age >= 18)
);


//                                        SELECT                                        //

--- The SELECT statement is used to retrieve data from a database. It allows you to specify which columns you want to retrieve and from which table.

Syntax:
SELECT column1, column2, ...
FROM table_name;

where:
- column1, column2, ...: The columns you want to retrieve. You can use * to select all columns.
- table_name: The name of the table from which you want to retrieve data.

• WHERE Clause
--- The WHERE clause is used to filter records based on specific conditions. It allows you to specify criteria that the retrieved data must meet.

--- These operators are used to perform mathematical operations on numeric data. Common arithmetic operators include:
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

• logical operators
--- Logical operators are used to combine multiple conditions in a WHERE clause. Common logical operators include:
- AND: Returns true if both conditions are true.
- OR: Returns true if at least one condition is true.

• AS Keyword
--- The AS keyword is used to rename a column or table in the result set of a query. It allows you to give a temporary name (alias) to a column or table for better readability.

Syntax:
SELECT column_name AS alias_name
FROM table_name;

• List ->  In or Not In Operator
--- The IN operator is used to specify multiple values in a WHERE clause. It allows you to check if a value matches any value in a list.

Syntax:
SELECT column_name(s) FROM table_name
WHERE column_name IN (value1, value2, ...);

//  --------------------------------------------------------------------------------------
• Range -> Between Operator
--- The BETWEEN operator is used to filter the result set within a certain range. It allows you to specify a range of values for a column.

Syntax:
SELECT column_name(s) FROM table_name
WHERE column_name BETWEEN value1 AND value2;

//  --------------------------------------------------------------------------------------
• Like Operator
--- The LIKE operator is used in a WHERE clause to search for a specified pattern in a column. It is often used with wildcard characters to match patterns in string data.

Wildcard Characters:
- %: Represents zero or more characters.
- _: Represents a single character.

Syntax:
SELECT column_name(s) FROM table_name
WHERE column_name LIKE pattern;

⇛ Working of like operator:

Example             Use
a%                 Starts with 'a'
%a                 Ends with 'a'
%a%                Contains 'a'
_a%                Starts with any single character, followed by 'a'
%a_                Ends with 'a', preceded by any single character

Syntax:

3. AVG() -> It is used to return the average value of a numeric column.
Syntax:

4. MAX() -> It is used to return the maximum value of a column.
Syntax:

5. MIN() -> It is used to return the minimum value of a column.
Syntax:

//                                   GROUP BY CLAUSE                                    //
//--------------------------------------------------------------------------------------//
--- It is used to group rows that have the same values in specified columns into summary rows, like "Find the number of employees in each department".
Syntax:
SELECT column_name(s), aggregate_function(column_name)
FROM table_name
WHERE condition
GROUP BY column_name(s);

//--------------------------------------------------------------------------------------//
//                                    HAVING CLAUSE                                     //
//--------------------------------------------------------------------------------------//

--- It is used to filter groups based on a specified condition.
Syntax:
SELECT column_name(s), aggregate_function(column_name)
FROM table_name
WHERE condition
GROUP BY column_name(s)
HAVING condition;

** IMP Rule **
before group by -> where condition is applied
after group by -> having condition is applied

** IMP Rule **
Aggregate functions are compulsory in having clause.
Aggregate functions cannot be used in the WHERE clause, but they can be used in the HAVING clause to filter groups based on aggregate values.

DIfference between WHERE and HAVING clause:
                        WHERE Clause	    |       HAVING Clause
                    ------------------------|------------------------
            Filters rows before grouping	| Filters groups after grouping
            Cannot use aggregate functions	| Can use aggregate functions
            Can be used without GROUP BY	| Must be used with GROUP BY
Can be used in update and delete statements	| Cannot be used in update and delete statements

--- A JOIN clause is used to combine rows from two or more tables based on a related column between them. 
--- It allows you to retrieve data from multiple tables in a single query.

# Types of JOINs:

1. INNER JOIN: Returns records that have matching values in both tables.
Syntax:
SELECT column_name(s) FROM table1
INNER JOIN table2
ON table1.common_column = table2.common_column;


2. LEFT JOIN (or LEFT OUTER JOIN): Returns all records from the left table and the matched records from the right table. If there is no match, the result is NULL on the right side.
Syntax:
SELECT column_name(s) FROM table1
LEFT JOIN table2
ON table1.common_column = table2.common_column;


3. RIGHT JOIN (or RIGHT OUTER JOIN): Returns all records from the right table and the matched records from the left table. If there is no match, the result is NULL on the left side.
Syntax:
SELECT column_name(s) FROM table1
RIGHT JOIN table2
ON table1.common_column = table2.common_column;


4. FULL OUTER JOIN: Returns all records when there is a match in either left or right table. If there is no match, the result is NULL on the side that does not have a match.
Syntax:
SELECT column_name(s) FROM table1
FULL OUTER JOIN table2
ON table1.common_column = table2.common_column;


5. CROSS JOIN: Returns the Cartesian product of the two tables, meaning it returns all possible combinations of rows from both tables.
Syntax:
SELECT column_name(s) FROM table1
CROSS JOIN table2;


6. SELF JOIN: A self join is a regular join but the table is joined with itself. It is used to compare rows within the same table.
Syntax:
SELECT a.column_name, b.column_name
FROM table_name a
JOIN table_name b
ON a.common_column = b.common_column
WHERE condition;
