• What is Conditional Rendering?
--- Conditional Rendering is a powerful technique in React that allows you to dynamically display content based on certain conditions.



// ---- Ternary Operator Syntax (for Conditional Rendering) ------------------------------

--> condition ? trueExpression : falseExpression
Eg. {isLoggedIn ? <Dashboard /> : <Login />}



// AND Operator Syntax (for Conditional Rendering) ------------------------------
--- Displays the expressionToRenderIfTrue only if the condition is true.

--> condition && expressionToRenderIfTrue
Eg. {isLoggedIn && <Dashboard />}



// OR Operator Syntax (for Conditional Rendering) ------------------------------
--- Displays the expressionToRenderIfFalse only if the condition is false.

--> condition || expressionToRenderIfFalse
Eg. {isLoggedIn || <Login />}

• What is useForm hook's puspose?
=> Simplify Form Management-------------------
--- The useForm() hook streamlines form handling by managing state, validation,and submission of form data.

--- By abstracting away the complexity of form management, useForm() can improve the performance and maintainabilityof your application.

--- The useForm() hook can be easily shared across multiple components, promoting code reuse and consistency.

• How to use useForm() hook?
--- Install react-hook-form library:
    >npm install react-hook-form
--- Import useForm from react-hook-form:
    --> import { useForm } from 'react-hook-form';
--- Initialize useForm in your component:
    --> const { register, handleSubmit, formState: { errors } } = useForm();
--- Register form fields using the register function:
    --> <input {...register('fieldName', { required: true })} />
--- Handle form submission using handleSubmit:
    --> <form onSubmit={handleSubmit(onSubmit)}></form>
--- Access form errors using the errors object:
    --> {errors.fieldName && <span>This field is required</span>}
--- Define the onSubmit function to process form data:
    --> const onSubmit = data => { console.log(data); };
--- By following these steps, you can effectively use the useForm() hook to manage forms in your React applications.

• What is useReducer hook's puspose?
--- A alternative of useState Hook.

• What is Reducer?
--- A pure function used for managing complex state logic in a predictable manner.
--- A Reducer function takes the current state and an action as arguments, and returns the next state.

• What is useReduce?
--- The useReducer Hook integrates reducers into functional React components, providing the current state and a dispatch function to send actions.

• How to use useReducer hook?
    --> import { useReducer } from 'react';
    --> const [state, dispatch] = useReducer(reducer, initialState);
        - reducer: function that decides how state changes.
        - initialState: starting state
        - state: current state
        - dispatch: function to send actions

    --> const reducer = (state, action) => {
            switch (action.type) {
                case 'increment':
                    return { count: state.count + 1 };
                case 'decrement':
                    return { count: state.count - 1 };
                default:
                    return state;
            }
        };

• What is Memoization?
--- An optimation technique that stores previously computed results to avoid redundant calculations.

• When to use?
--- Apply when components re-render unnecessarily or when handling expensive computations.

• useMemo Hook : -
--- Memoizes expensive calculations to prevent re-execution unless dependencies change.

Syntax:
--> const memoizedValue = useMemo(() => computeExpensiveValue(a, b), [a, b]);
